## 1. 渲染管线设置（UE5.8）

### 1.1 项目级

| 设置 | 值 | 理由 |
|---|---|---|
| 渲染方式 | **3D 场景 + 正交相机**（而非 Paper2D） | Paper2D 维护弱；正交 3D 可用完整 Niagara / 材质 / 后处理 |
| 单位换算 | **1 px = 1 uu** | 直接沿用原作所有数值，避免换算错误 |
| 相机投影 | Orthographic，`OrthoWidth = 1920` | 对应原作 1920×1080、`stretch mode = 2d` / `aspect = keep` |
| 光照 | **全 Unlit** | 原作是纯 2D 贴图，无光照 |
| Lumen / Nanite / VSM | **全部关闭** | 无意义开销 |
| 抗锯齿 | FXAA 或 关闭（像素风建议关） | 保持像素锐利 |
| 纹理过滤 | **Nearest**（`TF_Nearest`），Mip 关闭 | 像素风必须 |
| sRGB | 开 | |
| 目标帧率 | 渲染与逻辑均**不锁帧**（可变 `DeltaTime`）；**手感必须帧率无关** | 见 §00 §2 / §09 §2 |

### 1.2 ★ 分辨率与画幅适配

原作：设计分辨率 **1920×1080**，`stretch mode = 2d`、`aspect = keep`（**非 16:9 时加黑边**，可视范围恒定）。

这直接影响 gameplay 公平性：**正交相机若按宽度拉伸，超宽屏玩家能提前看到更多敌人**，与"敌人从屏外刷出"的紧张感设计冲突。

| 场景 | 策略 |
|---|---|
| **世界相机（gameplay）** | 固定 `OrthoWidth = 1920` **且** 固定垂直可视 1080 → 走 `aspect = keep` 等价方案：**保持 16:9 安全画幅，多余部分加黑边（Pillarbox/Letterbox）** |
| UE 实现 | `UGameViewportClient` 子类覆写 `LayoutPlayers()` / 设置 `FViewport` 的 `bConstrainAspectRatio = true`；或在 `APlayerCameraManager` 里按窗口比例动态调整 `OrthoWidth`，使**较短的一边始终映射到 1080**（即 `OrthoWidth = 1080 × min(AR, 16/9) × ...`）—— 二者任选其一，但必须保证**可视世界矩形恒为 1920×1080 uu** |
| 16:10 / 4:3（1280×800、1024×768） | 上下留黑边（Letterbox） |
| 21:9 / 32:9 | 左右留黑边（Pillarbox） |
| Steam Deck 1280×800 | 按 16:10 处理；UI 字号建议默认 `font_size = 1.2` |
| **UI（HUD/菜单）** | **不加黑边**，允许铺满全屏。CommonUI + `ScaleBox`；DPI Curve 以 1080p 为基准 |
| UI Safe Area | HUD 四角元素（血条/波次/待处理列表）内缩 **≥ 48 px**；`UCommonUIActionRouter` 的焦点提示不要贴边 |
| 分辨率变更 | 仅影响渲染，**绝不影响逻辑**（逻辑坐标系恒为 2048×1536 世界 + 1920×1080 视口） |

> **验收**：在 16:9 / 16:10 / 21:9 三种窗口下，玩家站在地图正中时**屏幕内可见的地图格数必须完全相同**（见 §8 V11）。

### 1.3 排序（Sorting）

原作依赖 Godot 的 Y-Sort。UE5 侧方案：

```
Z 轴 = -Y（世界 Y 越大，Z 越小 → 越靠前）
或：Translucency Sort Priority = FMath::RoundToInt(-WorldY)
```

**层级（从后到前）**：
```
0  背景渐变（全屏 Quad）
1  TileMap 地面
2  地面装饰 / 尸体
3  材料 / 消耗品 / 结构物
4  单位（按 Y 排序：玩家、敌人、树）
5  武器（挂在单位上，同层微调 +0.1）
6  投射物
7  粒子 / 爆炸
8  飘字（WorldUI CanvasLayer）
9  HUD（UI CanvasLayer）
10 暗屏 / 暗角 / 弹窗
```

## 4. 音频规范

### 4.1 音频总线

```
Master
├─ Sound    （SFX）
└─ Music
```
默认音量：`master 0.5`、`sound 0.75`、`music 0.25`（线性，转 dB 用 `linear2db`）

### 4.2 SFX 播放器池

| 参数 | 值 |
|---|---|
| `MAX_SOUNDS`（待播队列上限） | **32** |
| `num_players`（并发播放器） | **12** |
| bus | `"Sound"` |
| `pause_mode` | `PROCESS`（暂停时仍工作） |
| 出队速率 | **每帧 1 条**（Godot 实现细节） |
| 音高随机 | `pitch_scale = 1 + rand(-pitch_rand, pitch_rand)` |

> ★ **UE5 做法**：用 `USoundConcurrency`（Max Count 12，Resolution Rule = Stop Oldest）作为唯一裁剪机制，
> **不复刻"32 长度队列 + 每帧出队 1 条"** —— 那是 Godot 侧的节流手写实现。
> 若需避免同一瞬间同源音效叠爆，改用**同源同类 0.03 s 去重窗口**（时间基、帧率无关）。

**UE 侧配置**：

> **★ `shooting_sounds` 变体数实测分布**（扫描 `weapons/**/*_stats*.tres` 的数组长度，共 188 个条目）：
>
> | 变体数 | 0 | 1 | 2 | 3 | 4 | 5 | 8 | 9 |
> |---|---:|---:|---:|---:|---:|---:|---:|---:|
> | 条目数 | 4 | 14 | 11 | **71** | **29** | **55** | 4 | 4 |
>
> 即**主流是 3–5 条/阶位**（占 82%），不是 1–2 条。原作靠"多变体 + pitch ±0.2 随机"避免高攻速下的机枪式重复音，**只给 1 条会立刻听出机械感**。
> 制作口径建议：**按武器家族做 3–5 条**，同家族 4 个阶位共用（原工程多数阶位就是复用同一组 WAV），音调/厚度差异用 `sound_db_mod` 与 pitch 表现。`0 条` 的 4 个条目是炮塔/伪武器（garden 等）。

| 项 | 配置 |
|---|---|
| `USoundConcurrency` | `MaxCount = 12`，`ResolutionRule = StopOldest`，`bLimitToOwner = false` |
| 同源去重 | 同一音效源 + 同类事件在 **0.03 s** 内只播 1 条（替代原作"32 队列 + 每帧出队 1 条"的手写节流） |
| 2D vs 3D | `SoundManager` = **2D**（UI / 玩家自身）；`SoundManager2D` = **带衰减的位置音**（敌人受击/爆炸/燃烧） |
| 衰减曲线 | 位置音 `AttenuationShape = Sphere`，`InnerRadius = 400`，`FalloffDistance = 1200`（约 1 个屏宽半径），Linear |
| Pitch 随机 | `USoundCue` 的 `Modulator` 节点，`PitchMin/Max = 1 ± pitch_rand` |
| 总线 | `Master` → `Sound` / `Music` 两条 `USoundSubmix`；音量用 `SetSubmixOutputVolume(linear)` |
| 暂停时 | 音频 Submix **不受暂停影响**（对齐 `pause_mode = PROCESS`） |

### 4.7 失焦处理

`settings.mute_on_focus_lost` 为真时，窗口失焦静音 Master，恢复时还原。
`settings.pause_on_focus_lost`（**默认开**）为真时，失焦或手柄断开 → 自动暂停。

## 6. 字体与本地化排版

| 项 | 值 |
|---|---|
| 最小字号基准 | `SMALLEST_FONT_BASE_SIZE = 20` |
| 字号设置 | `smallest_text_font.size = 20 × settings.font_size`（滑杆，默认 1.0） |
| 内联图标尺寸 | `[img=WxH]`，`W = 20 × settings.font_size` |
| 富文本 | 大量使用 BBCode：`[color=#00ff00]`、`[color=red]`、`[img=WxH]path[/img]` |
| 语言 | 13 种：de, en, es, fr, it, ja, ko, pl, pt, ru, tr, zh, zh_TW |

> UE5 对照：`FText` + `URichTextBlock` + `URichTextBlockImageDecorator`；字号缩放通过 `UCommonTextStyle` 动态切换或 Slate 全局 `ApplicationScale`。

### 6.1 ★ BBCode → URichTextBlock 逐标签映射

| Godot BBCode | UE5 实现 | 说明 |
|---|---|---|
| `[color=#00ff00]…[/color]` | `<Positive>…</>` | 在 `DataTable` 形式的 `RichTextStyleSet` 里预置命名样式，**不要动态拼颜色** |
| `[color=red]…[/color]` | `<Negative>…</>` | |
| `[color=#555555]…[/color]` | `<Secondary>…</>` | `GRAY_COLOR_STR` |
| Tier 颜色（运行时取自 tier） | `<Tier1>` / `<Tier2>` / `<Tier3>` / `<Tier4>` / `<Danger4>` / `<Danger5>` / `<Danger0>` | 7 个固定样式，见 §2.4 |
| `[img=WxH]path[/img]` | `<img id="stat_armor"/>` + **`URichTextBlockImageDecorator`** | 图标以 **id** 索引 `DataTable(RichImageRow)`，不写路径 |
| 内联图标尺寸 | 在 `RichImageRow.ImageSize` 里填 `20 × font_size`，或用 `bMatchTextHeight = true` **自动随字号缩放**（推荐，省去动态改表） |
| 属性飘字的图标 `scale 0.5` | 单独一套 `RichImageRow`（尺寸减半）或 `FloatingText` 直接用 `UImage` 而非富文本 |

**字号缩放实现**：
```
smallest_text_font.size = 20 × settings.font_size
→ UE：FSlateApplication::Get().SetApplicationScale(settings.font_size)
   （全局缩放，图标与文字自动同步；优于逐 TextStyle 改 size）
```
注意 `SetApplicationScale` 会同时缩放 HUD 布局，需确认 §1.2 的 Safe Area 在 `font_size = 1.5` 时仍不溢出。

### 6.2 CJK 字形与字体资产

| 项 | 要求 |
|---|---|
| 拉丁/数字 | 像素风主字体（含 `font_end_run` 结算大字体，共 2 套） |
| **中文** | 像素风中文字体（如"方正像素""Zpix"），需覆盖 **GB2312 一级 + 游戏内用字**；`UFont` 用 **Offline Cached**（离线烘焙）而非 Runtime，避免首次渲染卡顿 |
| 日/韩（P2） | 若上 ja/ko，需另备字形；`Composite Font` 按 Unicode 区间 fallback |
| Fallback | `UFont` 的 `CompositeFont` 配 `Default` + `SubTypefaces`（CJK 区间指向中文字体） |
| 字号档位 | 20 / 24 / 28 / 40（结算）；Offline Cache 只烘这几档，避免任意缩放模糊 |

## 8. 验收用例

```
V01 受击 → 白闪恰好 0.1 s，闪避时不白闪
V02 屏震偏移采样 1000 次 → x,y 全部 ≥ 0（只向右下）
V03 屏震覆盖规则：同一 Tick 内先受 3 伤（强度 1）再受 30 伤（强度 3）→ 最终强度 **1**（因覆盖需 `强度>当前` **且** `时长>当前`，而两者时长同为 0.1 s）；顺序相反则为 3
V04 打开/关闭 screenshake / visual_effects / damage_display 三个开关均生效
V05 飘字：同屏 >100 时新飘字被丢弃，但玩家受伤飘字仍显示（always_display）
V06 子弹发射后 **0.02 s** 内原地不动，之后开始移动
V07 爆炸命中窗口：一个敌人在爆炸 0.1 s 后进入范围 → 不受伤
V08 音效：连续 50 次命中 → 并发不超过 12 个播放器，无爆音
V09 近战音效时刻早于 hitbox 开启（可用日志时间戳验证）
V10 相机：玩家走到地图左上角 → 相机停在 limit (−96, −192)
V11 画幅：16:9 / 16:10 / 21:9 三种窗口下，玩家居中时可见地图格数完全相同（黑边而非扩视野）
V12 字号：font_size 从 1.0 调到 1.5 → 文字与内联图标同步放大，且 HUD 无溢出/重叠
V13 音频：位置音在距玩家 1200 px 外基本听不到；UI 音不受距离影响
```
