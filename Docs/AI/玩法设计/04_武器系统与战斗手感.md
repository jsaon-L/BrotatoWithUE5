### 1.1 `WeaponStats`（基类，`weapons/weapon_stats/weapon_stats.gd`）

|---|---|---|---|

### 1.2 `MeleeWeaponStats`

| 字段 | 说明 |
|---|---|
| `deal_dmg_on_return` | 回收阶段也保留 hitbox |

### 1.3 `RangedWeaponStats`

| 字段 | 默认 | 说明 |
|---|---|---|
| `nb_projectiles` | 1 | 一次射击的弹数 |
| `projectile_spread` | 0.0 | 每发在 ±spread 弧度内随机 |
| `piercing` / `piercing_dmg_reduction` | 0 / 0.5 | 穿透次数 / 每次穿透伤害衰减比例 |
| `bounce` / `bounce_dmg_reduction` | 0 / 0.5 | 弹射次数 / 衰减 |
| `projectile_speed` | 3000 | px/s |
| `increase_projectile_speed_with_range` | false | 弹速随 `stat_range` 提升 |
| `projectile_scene` | `bullet_projectile.tscn` | |

显示冷却（秒） = `recoil_duration × 2 + CooldownSeconds`

### 1.4 `WeaponData`（商店/背包层）

```gdscript
weapon_id : String       # 家族 id，"weapon_dagger"（4 阶共用，解锁按此粒度）
my_id     : String       # 唯一 id，"weapon_dagger_1"（合成判定按此）
type      : {MELEE=0, RANGED=1}
sets      : Array[SetData]     # 所属职业（可多个）
scene / stats / upgrades_into
tier      : 0=I(白) 1=II(蓝) 2=III(紫) 3=IV(红)
value     : 商店价格基数
effects   : Array[Effect]
dmg_dealt_last_wave / tracked_value
```

> **命名不一致警告**：`weapons/melee/cactus_mace/` 的 `my_id = "weapon_cacti_club_1"`，`weapon_id = "weapon_cacti_club"` —— 文件夹名与 ID 不同。建表时**以 `weapon_id` 为准**。
> `weapons/melee/knuckles/` 的 `weapon_id = ""`，是特殊武器（不进商店池）。

## 2. 武器职业（Set）与套装加成

### 2.1 生效逻辑（`run_data.gd:462-485`）

```gdscript
# 先全撤销
for effect in active_set_effects: effect[1].unapply()
active_set_effects = []; active_sets = {}
# 重新统计
for weapon in weapons: for set in weapon.sets: active_sets[set.my_id] += 1
for key in active_sets:
    if active_sets[key] >= 2:
        set_effects = set.set_bonuses[min(active_sets[key] - 2, 4)]
        for effect in set_effects: effect.apply()
```

**★ 不叠加**：只有"当前件数对应的那一档"生效。7 件以上仍按 6 件档。
档位索引 = `min(件数 − 2, 档位数 − 1)`，即 2 件 = 档 0 … 6 件 = 档 4。

## 7. 自动瞄准与开火判定

### 7.1 目标选择（`weapon.gd:104-188`）

```gdscript
func _physics_process(delta):
    if ProgressData.is_manual_aim():
        rotation = (get_global_mouse_position() - global_position).angle()
    else:
        rotation = get_direction() if _is_shooting else get_direction_and_calculate_target()
    if not _is_shooting:
        _current_cooldown = max(_current_cooldown - Utils.physics_one(delta), 0)
    if should_shoot(): shoot()
```

- **选靶规则 = 距离该武器最近、且距离 ≥ `min_range` 的敌人**（`Utils.get_nearest`，内部 max_range 传 9999 即不设上限）
- `Range` Area2D 的 `body_entered/exited` 维护 `_targets_in_range`，半径 = `max_range + 200`
- **射击中锁定当前目标**，目标失效才重算
- 无目标时使用 `_current_idle_angle`

### 7.2 开火条件（全部满足）

```
1. 冷却已就绪（原作 _current_cooldown == 0；UE 侧 = Cooldown GE 已过期 / 无冷却 Tag）
2. effects["can_attack_while_moving"] 为真  或  玩家 _current_movement == Vector2.ZERO
3. 目标有效且 Utils.is_between(距离, min_range, get_max_range())
   其中 get_max_range() = max_range + 50   （近战横扫模式下 = max_range 本身）
4. 或处于手动瞄准模式（且未清场）
```
> Soldier 的 `can_attack_while_moving = 0` 即在此生效 —— **移动时完全不开火**。

### 7.3 散布

```gdscript
_current_shoot_spread = rand_range(-(1 - accuracy), (1 - accuracy))   # 弧度
rotation += _current_shoot_spread
```
`accuracy = 1.0` 时零散布。

### 7.4 冷却计算（★ 含随机抖动）

**原作逻辑（帧）**：

```gdscript
get_next_cooldown():
    if is_big_reload_active(): return cooldown × additional_cooldown_multiplier
    max_rand = get_max_rand_cooldown()
    return rand_range(max(1, cooldown - max_rand), cooldown + max_rand)

get_max_rand_cooldown():
    n = min(玩家武器数, 6)
    return min(n × cooldown / 5.0, n × 5.0)

is_big_reload_active(): additional_cooldown_every_x_shots != -1 and _nb_shots_taken % X == 0
reset_cooldown(): _current_cooldown = min(_current_cooldown, cooldown × (mult if big_reload else 1))
```

**★ UE 实现（秒，等价式）**：

```cpp
// CD = CooldownSeconds（= 原作 cooldown / 60）
if (bBigReload) return CD * AdditionalCooldownMultiplier;
const int32 N = FMath::Min(WeaponCount, 6);
const float R = FMath::Min(N * CD / 5.f, N * (5.f / 60.f));      // 上限 ±0.5 s
return Rng.RandRange(FMath::Max(1.f / 60.f, CD - R), CD + R);    // ★ 不取整
```

| 项 | 原作（帧） | UE（秒） |
|---|---|---|
| 抖动上限 R | `min(n×cd/5, n×5)`，最大 30 | `min(n×CD/5, n×0.0833)`，最大 0.5 |
| 抖动下限 | `max(1, cd-R)` | `max(1/60, CD-R)` |
| 攻速后冷却下限 | `max(2, ...)` | `max(1/30, ...)` |
| 结果取整 | 截断向零（`31.9 → 31`） | ❌ **不取整**（时间量全程 float，见 §00 §6） |
| 计时起点 | 开火时设定，射击期间冻结 | **攻击序列结束时 Apply Cooldown GE**（等价） |

**设计意图**：武器数越多，冷却抖动越大（最多 ±0.5 s），用来**把多武器的射击错开**，避免所有武器同时齐射造成的视觉与音效爆炸。

> `reset_cooldown()` 的等价实现：`ModifyActiveGameplayEffectStartTime()` 压缩剩余时长（§09 §9.3 / D04 §3.2）。

## 8. 近战攻击时序（★ 手感核心）

`weapons/shooting_behaviors/melee_weapon_shooting_behavior.gd` + `melee_shooting_data.gd`

### 8.1 时长计算

```gdscript
BASE_ATK_DURATION = 0.2
atk_spd      = (stat_attack_speed + attack_speed_mod) / 100.0
range_factor = max(0, max_range / clamp(70.0 × (1 + atk_spd/3), 70.0, 120.0))
atk_duration = max(0.01, 0.2 - atk_spd/10.0) + range_factor × 0.15
back_duration= 0.2 / (1 + atk_spd × 3)    if atk_spd > 0  else  0.2
shooting_total_duration = atk_duration/2 + back_duration + recoil_duration
```

### 8.2 THRUST（突刺）序列

| 阶段 | 动作 | 时长 | 缓动 |
|---|---|---|---|
| 1 | 后拉：`Sprite.position → (x - recoil, y)` | `recoil_duration`（默认 0.1 s，被攻速除算） | `TRANS_EXPO / EASE_OUT` |
| 2 | **播放攻击音 + `enable_hitbox()`** | 瞬时 | — |
| 3 | 前刺：`position → (x + max_range, y)` | `atk_duration / 2` | `EXPO / OUT` |
| 4 | `deal_dmg_on_return == false` → `disable_hitbox()` | 瞬时 | — |
| 5 | 收回：`position → initial` | `back_duration` | — |
| 6 | `deal_dmg_on_return == true` → 此时才 `disable_hitbox()` | 瞬时 | — |
| 7 | `set_shooting(false)`（冷却开始递减） | — | — |

### 8.3 SWEEP（横扫）序列

```gdscript
MIN_SWEEP_DISTANCE = 250
atk_distance = min(max_range, max(250, 到目标距离))
update_atk_duration(atk_distance)
side_range   = atk_distance / 2
sweep_angle  = 0.9 × PI                    # ≈ 162°
sweep_half_duration = atk_duration / 4
```

| 阶段 | 动作 | 时长 | 缓动 |
|---|---|---|---|
| 1 | 起手：`position → (x - recoil, y ± side_range)`，`rotation → ±0.9π`（符号由 flip_v 决定） | `recoil_duration` | `EXPO / OUT` |
| 2 | **音效 + `enable_hitbox()`** | — | — |
| 3 | 前半扫：`position → (x + sweep_range×0.75, y)`，`rotation → 0` | `sweep_half_duration` | **`TRANS_LINEAR`** |
| 4 | 后半扫：`position → (x - recoil, y ∓ side_range)`，`rotation → ∓0.9π` | `sweep_half_duration` | **LINEAR** |
| 5 | `disable_hitbox()`（除非 `deal_dmg_on_return`） | — | — |
| 6 | 收回 | `back_duration` | `EXPO / OUT` |

> **手感密码**：起手/收回用 `EXPO/OUT`（快起慢收，制造"甩"感），扫动段用 `LINEAR`（匀速，保证判定均匀）。这组曲线搭配是 Brotato 近战"有重量"的来源，**必须照抄**。

### 8.4 命中规则

- Hitbox 是 `Area2D` + `RectangleShape2D`
- **一次挥击内每个敌人只吃 1 次伤害**：命中后把目标 push 进 `_hitbox.ignored_objects`，`Unit._on_Hurtbox_area_entered` 检查后直接 return
- `disable_hitbox()` 会 `ignored_objects.clear()` → 下次挥击重新可命中
- **"多段命中"靠高攻速/低 cooldown 实现**（如 Drill CD = 0.0167 s）
- 原作 Hitbox 的启用/禁用走 `set_deferred("disabled", ...)`，**存在 1 帧延迟** —— ★ **UE 侧不复刻该延迟**，改为立即生效 + `IgnoredThisSwing` 去重（§00 §3.3）

### 9.1 射击流程（`ranged_weapon_shooting_behavior.gd`）

### 9.3 命中处理

```gdscript
_on_Hitbox_hit_something(thing_hit):
    ignored_objects = [thing_hit]
    if bounce > 0:        bounce(thing_hit)
    elif piercing <= 0:   set_to_be_destroyed()
    else:
        piercing -= 1
        damage = max(1, damage - damage × piercing_dmg_reduction)
    RunData.manage_life_steal(weapon_stats)

    bounce -= 1
    target = 随机敌人（无则随机角度）
    velocity = Vector2.RIGHT.rotated(dir) × velocity.length()
    weapon_stats.max_range = 99999      ← 弹射后不再受射程限制
    击退清零
    damage = max(1, damage - damage × bounce_dmg_reduction)

_on_Hitbox_critically_hit_something():
    "effect_bounce_on_crit" → bounce += 1, effect.value -= 1（用尽则移除）
    "effect_pierce_on_crit" → piercing += 1, effect.value -= 1
```

> **追踪机制只存在于 bounce（弹射转向随机敌人）**，没有常规导弹式 homing。

### 9.4 ★ `recoil` / `recoil_duration` 全量配置

后坐是**纯视觉位移**（近战起手后拉、远程开火后座），但它同时进入时序公式，**直接影响 DPS**：

```
近战 shooting_total_duration = atk_duration/2 + back_duration + recoil_duration
远程 atk_duration            = recoil_duration × 2        ← 这段时间内不递减冷却
两者都被攻速除算：recoil /= (1+atk_spd)，recoil_duration /= (1+atk_spd)
```

**默认值 `recoil = 25` / `recoil_duration = 0.1`**（`weapon_stats.gd:19-20`）。全工程 185 个阶位中**只有下列条目覆写了默认值**，其余（含全部近战，Drill 除外）一律用默认：

| SMG | I–IV | 10 | 0.05 | |
| Minigun | III | 10 | 0.02 | |
| Minigun | IV | **3** | 0.02 | 与 III 不同，勿沿用 |
| Chain Gun | IV | 3 | 0.02 | |
| Gatling Laser | IV | 3 | 0.02 | |
| Flamethrower | II–IV | 5 | 0.02 | |
| Potato Thrower | II / III / IV | 25 / **15** / **10** | 0.1 | 逐阶递减 |
| Crossbow | I–IV | 30 | 0.15 | |
| Shredder | I–IV | 40 | 0.15 | |
| Slingshot | I–IV | 40 | 0.15 | |
| Wand | I–IV | 40 | 0.1 | |
| Laser Gun | I–IV | 40 | 0.2 | |
| Sniper Gun | III–IV | 40 | 0.2 | 子弹溅射用的 `*_proj_stats` 仍是 25 / 0.1 |

> 另：`recoil` 位移量与伤害判定无关，近战 hitbox 在后拉**结束后**才开启（见 §8.2 阶段 2）。

## 10. 打击感（Game Feel）参数全表

### 10.1 屏幕震动（`global/screenshaker.gd`）

```gdscript
玩家受伤 (value != 0):  shake(5, 0.1)
任意单位受伤:           shake(min(value/3.0, 3), 0.1)        # 强度上限 3

shake(intensity, duration):
    if not settings.screenshake: return
    # ★ 只有 强度 > 当前 且 时长 > 当前 才覆盖（同一时刻不叠加）
    if intensity > _intensity and duration > _duration: 赋值

_process(delta):
    if duration <= 0: camera.offset = ZERO; return
    duration -= delta
    camera.offset = Vector2(randf(), randf()) × intensity      # ★ randf()∈[0,1)，只向右下偏移
```

| 事件 | 强度 | 时长 |
|---|---|---|
| 敌人受击 | `min(dmg/3, 3)` px | 0.1 s |
| 玩家受击 | 5 px | 0.1 s |

**无衰减曲线** —— 整段恒定强度，到时间直接归零。**偏移方向只向 (+x, +y)**，这是原作独特"抖动感"的来源，复刻时不要改成对称随机。

> **★ 覆盖条件是 `强度 > 当前` 且 `时长 > 当前`（两个都要满足）**。由于全游戏所有屏震的 `duration` 都是 **0.1 s**，`duration > _duration` 在同一段震动未结束前恒为 false ——
> **结论：一段震动期间内，后续任何震动请求都无法覆盖它，实际生效的永远是"这段震动的第一个触发者"**，与强度大小无关。
> 例：同一 Tick 内先受 3 伤（强度 1）再受 30 伤（强度 3）→ 最终强度 **1**；若顺序相反 → 强度 **3**。这是原作行为，照抄（对应 §07 V03 用例）。

### 10.2 命中停顿（Hitstop）

**❌ 不存在。** 全代码无 `Engine.time_scale` / 时间冻结相关逻辑。
近战"顿感"完全由 Tween 的 `EXPO/OUT` 前重后轻曲线 + `recoil_duration` 起手 + `back_duration` 收回构成。

> 复刻时**不要擅自加 hitstop**，会让手感偏离原作（原作攻速可以堆到每秒十几次，hitstop 会造成卡顿）。

### 10.6 击退表现


★ **UE 侧（帧率无关等价式）**：


## 11. 武器合成与槽位

### 11.1 合成条件（`run_data.gd:643-650`）

```gdscript
func can_combine(weapon_data) -> bool:
    nb_duplicates = 拥有 my_id 完全相同的武器数量        # my_id 含 tier
    return nb_duplicates >= 2
       and weapon_data.upgrades_into != null            # tier IV 无
       and weapon_data.tier < effects["max_weapon_tier"]
```
即 **同名 + 同 tier × 2 → 1 把 tier+1**。

### 11.2 合成执行（`shop.gd:325-349`）

```gdscript
on_item_combine_button_pressed(weapon_data, is_upgrade = false):
    nb_to_remove = 1 if is_upgrade else 2
    移除 UI 元素与 RunData 中的武器（共 nb_to_remove 把）
    new_weapon = RunData.add_weapon(weapon_data.upgrades_into)
    new_weapon.tracked_value = 两把的累加             # 统计继承

```

**免费升级（铁砧 `item_anvil`）**（`shop.gd:53-70`）：
```gdscript
for effect in effects["upgrade_random_weapon"]:
    candidates = 所有 upgrades_into != null 且 tier < max_weapon_tier 的武器
    if candidates: on_item_combine_button_pressed(随机一把, is_upgrade = true)   # 只消耗 1 把
```

**破坏武器**（`shop.gd:49-51`）：Arms Dealer 的 `destroy_weapons` 为真时，**进店即 `remove_all_weapons()`**。

### 11.3 槽位规则

```gdscript
max_weapons = 6                    # init_run

effects["max_melee_weapons"]  = 999
```

### 13.2 挥击动画实现方案

**不要用 AnimMontage**。用 `UAbilityTask`（`bTickingTask = true`）按**秒**推进的阶段状态机，缓动用 `UCurveFloat` 资产：
```cpp
enum class EMeleeSwingPhase { Recoil, Forward, SweepFirstHalf, SweepSecondHalf, Return, Done };
// 每阶段记录 PhaseElapsed / PhaseDuration（秒），TickTask 内推进并做「余量结转」
// EaseExpoOut(t) = 1 - pow(2, -10t)
// Linear(t) = t
```

### 13.3 Hitbox 实现

- 用 `UBoxComponent`（extents 直接照抄表格数值）挂在 Sprite 下
- 命中去重：每次 `EnableHitbox()` 时清空 `IgnoredActors`，命中后 Add
- ★ **立即启用/禁用**，不复刻原作 `set_deferred` 的 1 帧延迟（§00 §3.3）

### 13.4 投射物

- **对象池必做**（同屏可能数百发）
- 出膛后 `LaunchDelay = 0.02 s` 内原地不动 —— 这是"发射闪光"的停顿感
- 离屏 1 s 后回收，或飞行超过 `max_range + 100` 立即回收
