## 3. 模块划分与 Build.cs（全文）

### 3.1 依赖方向（严格单向，CI 校验）

```
BrotatoCore ← BrotatoData ← BrotatoGAS ← BrotatoGameplay ← BrotatoUI
                                     ↖ BrotatoSave ↗
BrotatoEditor → 以上全部（Editor-only）
```

**铁律**：
- `BrotatoCore` **不得** `#include` 任何 `GameplayAbilities` / `Engine` 的 Gameplay 类型（可用 `CoreUObject` 的 `FVector2D`/`USTRUCT`）。
- `BrotatoGameplay` **不得**反向依赖 `BrotatoUI`；UI 只能订阅 Gameplay 广播的委托。
- 任何模块**不得**依赖 `BrotatoEditor`。

### 3.2 `BrotatoCore.Build.cs`

```csharp
using UnrealBuildTool;

public class BrotatoCore : ModuleRules
{
    public BrotatoCore(ReadOnlyTargetRules Target) : base(Target)
    {
        PCHUsage = PCHUsageMode.UseExplicitOrSharedPCHs;
        // ★ 只允许这三个，新增依赖需要架构评审
        PublicDependencyModuleNames.AddRange(new[] { "Core", "CoreUObject", "GameplayTags" });
        bUseUnity = false;              // 防止隐式跨文件依赖
    }
}
```

## 4. 全局配置

### 4.1 GameplayTags 源

```ini
; DefaultGameplayTags.ini
[/Script/GameplayTags.GameplayTagsSettings]
ImportTagsFromConfig=True
WarnOnInvalidTags=True
FastReplication=False          ; 单机，不需要
InvalidTagCharacters="\"\',"
+GameplayTagTableList=/Game/Data/Tables/DT_GameplayTags.DT_GameplayTags
```

Tag 全量定义见 **D02 §1**。C++ 侧统一用 `UE_DEFINE_GAMEPLAY_TAG_STATIC` / `FBrotatoTags` 单例，**禁止在业务代码里写字符串字面量 Tag**。

### 4.2 ASC 与 Cue 全局设置

```ini
[/Script/GameplayAbilities.AbilitySystemGlobals]
AbilitySystemGlobalsClassName=/Script/BrotatoGAS.BrotatoAbilitySystemGlobals
bUseDebugTargetFromHud=False
bAllowGameplayModEvaluationChannels=False
GlobalAttributeSetDefaultsTableNames=/Game/Data/Tables/DT_AttributeDefaults.DT_AttributeDefaults
```

```cpp
// BrotatoGAS/Public/BrotatoAbilitySystemGlobals.h
UCLASS()
class BROTATOGAS_API UBrotatoAbilitySystemGlobals : public UAbilitySystemGlobals
{
    GENERATED_BODY()
public:
    /** 使用自定义 Context，携带「伤害来源物品 / 是否暴击 / 特效缩放」等信息 */
    virtual FGameplayEffectContext* AllocGameplayEffectContext() const override;

    /** 关闭 Cue 的异步加载抖动：启动时预载全部 Cue 资产 */
    virtual void InitGlobalData() override;

```

### 4.3 输入（Enhanced Input，对齐 §08 §6）

| IA 资产 | 类型 | 说明 |
|---|---|---|
| `IA_Move` | Axis2D | WASD/ZQSD/IJKL/方向键/左摇杆 |
| `IA_Aim` | Axis2D | 右摇杆 / 鼠标位置（手动瞄准） |

### 5.2 ★ 硬性禁令（CI 静态检查，违者构建失败）

| # | 禁止 | 替代 | 原因 |
|---|---|---|---|
| F1 | `FMath::RoundToInt` | `BrotatoMathInt::BrotatoRound` | Godot 是 half-away-from-zero，UE 是 half-to-+∞，负值分叉（D01 §3）。**仅适用于整数语义量**；时间/距离不取整 |
| F2 | 玩法逻辑里的 `FMath::FRand()` / `FMath::RandRange` | `UBrotatoRunSubsystem::GetRandom(Channel)` | 破坏可复现性；`Cosmetic` 用途例外（§00 §5.2） |
| F3 | ★ **整数帧计数器**（`int32 *FramesLeft`）做计时 | Duration / Periodic GE、`UAbilityTask`、`FTimerManager`、`Remaining -= DeltaTime` | 帧基计时与 UE 时间模型割裂，且帧率相关（§00 §2） |
| F4 | ★ **每 Tick 固定增减**（`X -= 1`、`V *= 0.9`） | `X -= DeltaTime`；`V *= Exp(-Rate*DeltaTime)` | 隐含 60 Hz 假设，帧率一变手感就变 |
| F5 | ★ 关闭 ASC Tick 后手动驱动 | 保持引擎默认 ASC Tick | 破坏 GAS 生命周期与 Pause/TimeDilation 正确性（§00 §3.4） |
| F6 | ★ 自建等待 Task（按帧倒数） | `UAbilityTask_WaitDelay` / `UAbilityTask_WaitGameplayEvent` | 原生 Task 已足够且行为正确（D04 §6.6） |
| F7 | 在 ExecCalc / MMC 内写公式 | 调 `FBrotatoDamageMath` | 双路径必须共享唯一实现 |
| F8 | `Array.Remove(值)` 卸载效果 | `FActiveGameplayEffectHandle` / `FGuid` | 原作 bug，同物品叠加会错删 |
| F9 | 业务代码里的 Tag 字符串字面量 | `FBrotatoTags::Get().XXX` / `UE_DEFINE_GAMEPLAY_TAG_STATIC` | 拼写错误无法编译期发现 |
| F10 | 每条 Effect 一个 GE | 一物品一 GE Spec | Aggregator 条目数 ×10 |
| F11 | ★ 复刻 Godot 的 deferred 延迟（1 帧 / 2 帧） | 立即生效 + 去重集合 / 秒级延迟 | 复刻的是实现副作用而非设计意图（§00 §3.3） |

> ★ **v2.0 反转**：旧版 F4/F5/F6 曾**禁止** Periodic GE / Duration GE / Cooldown GE，现已全部解禁并成为**推荐做法**（§00 §3.1）；
> 取而代之被禁止的是"自建帧计数器"与"帧率相关写法"。

例外白名单：`BrotatoMathInt` 内部可用 `FMath::FloorToInt`；`FBrotatoRandom` 内部可持有 `FRandomStream`；`Cosmetic` 表现层可用引擎随机。

### 5.3 注释与出处标注

任何**硬编码数值**必须带出处注释：

```cpp
// §02 §4.6 无敌窗口：MIN 0.2 s / MAX 0.4 s，阈值 15% 最大生命
static constexpr float MinIFrameSeconds = 0.2f;
static constexpr float MaxIFrameSeconds = 0.4f;
```

未标注出处的魔数视为缺陷，Code Review 打回。

### 5.4 日志分类

```cpp
DECLARE_LOG_CATEGORY_EXTERN(LogBrotato,       Log, All);   // 通用
DECLARE_LOG_CATEGORY_EXTERN(LogBrotatoGAS,    Log, All);   // GE/Ability/Cue
DECLARE_LOG_CATEGORY_EXTERN(LogBrotatoWave,   Log, All);   // 刷怪
DECLARE_LOG_CATEGORY_EXTERN(LogBrotatoDet,    Log, All);   // ★ 确定性追踪（黄金基线用）
```

`LogBrotatoDet` 只在 `-ExecCmds="Brotato.Determinism 1"` 时开启，输出各 RNG 流的 `CallCount / State` 与关键事件序列（商店/掉落/刷怪），用于定位分叉点。

## 8. 术语补充（本系列专用）

| 术语 | 含义 |
|---|---|
| **模拟阶段 / Sim Phase** | `UBrotatoSimSubsystem` 每 Tick 按固定顺序执行的 13 个阶段（S1–S13），游戏状态变更只在此发生；步长为真实 `DeltaTime` |
| **秒制时间基** | 全工程时间量唯一单位为秒（float）；原作帧值在导入期换算，运行时无帧字段（§00 §2） |
| **行为等价** | 验收对象是可观测量（攻击间隔、TTK、窗口时长），容差 ±2%；不要求与原作逐帧一致（§00 §1.1 P1） |
| **Tier A/B/C/D** | GAS 分级：玩家 / Boss·精英 / 普通敌人 / 无 Actor 实体（与稀有度 Tier 无关） |
| **计算核心** | `BrotatoCore` 内的纯静态函数集合，唯一公式真源 |
| **双路径** | GAS ExecCalc（Tier A/B）与纯函数 Pipeline（Tier C），必须结果一致 |
| **Hook（钩子槽）** | GAS 无法表达的事件型效果，存 `UBrotatoHookRegistry`；事件分发走 GameplayEvent |
| **RNG 流** | 按用途分区的 `FRandomStream`（Shop/Loot/Spawn/Combat/Cosmetic），均由 RunSeed 派生（§00 §5.2） |
| **黄金基线** | 固定 seed + 固定步长 headless 跑完整局后的状态快照 JSON，用于回归；**是本工程自己的历史快照，不是原作数据** |
