# D05 · 敌人、波次、刷怪、碰撞与结构物实现

> **模块**：`BrotatoGameplay`（Units / Behaviors / Wave / Subsystems / Structures）
> **里程碑**：M1 单敌人 + 单波 → M4 全敌人 + 20 波配表 + Boss/精英 → M6 Danger + 无尽
> **上游规格**：`Docs/00` 全文（★ 最高仲裁）、`Docs/06` 全文、`Docs/07 §1`、`Docs/09 §10 §11`
> **v2.0 变更**：全部计时字段由**整数帧改为秒（float）**，按 `-= DeltaTime` 推进；碰撞**默认用 UE 原生查询**（空间哈希降级为压测兜底）；Boss / 精英状态机改用 **StateTree**。

---

## 0. 分级实现总览

| Tier | 实体 | 同屏量 | 实现 |
|---|---|---|---|
| **B** | Boss(2) + 精英(8) | ≤ 4 | `ABrotatoBoss` + 轻量 ASC + 1 AttributeSet + **StateTree** |
| **C** | 普通敌人(21) + 树 + 结构物(9) | 100–144 | `FEnemyState` SoA 数组 + `UEnemySubsystem` 批处理 |
| **D** | 子弹(500) / 材料(50) / 飘字(100) | — | 结构体数组 + HISM/Niagara 批渲染 |

**AI 方案**：普通小兵用 `MovementBehaviorType` + `AttackBehaviorType` 两个枚举 + 按类型分桶批处理（与原作两个 Behavior 节点 1:1 对应，144 个 BT 实例是明确的性能灾难）；
**Boss / 精英 / 结构物（≤10 个）改用 UE5 原生 `StateTree`** —— 阶段递进与条件转移正是它的强项（§09 §10.3）。

## 2. 移动行为（6 种）

### 2.1 枚举与参数

```cpp
UENUM()
enum class EMovementBehavior : uint8
{
    FollowPlayer,                  // 永远直线追击
    StayInRangeFromPlayer,         // target_range 300, randomization 100
    TargetRandPos,                 // 全图随机点
    TargetRandPosAroundPlayer,     // range 300, randomization 100
    FollowRandPosAroundPlayer,     // range 200, randomization 0, allow_within true
    PatrolEdgesOfMap               // edge_distance 300, detection 300（Zone 1 未使用）
};
static constexpr float EqualityPrecision = 10.f;   // 到点判定半径 10 px
```

> ★ **无加速度、无转向速率** —— 方向归一化 × 当前速度（瞬时转向），位移 = `速度 × DeltaTime`。目标刷新"到点即换"，无定时器。

### 2.2 实现

```cpp
void UEnemySubsystem::StepMovement(float DeltaTime)
{
    const FVector2D PlayerPos = Player->GetPos2D();
    for (FEnemyState& E : Enemies)
    {
        if (!E.bActive || E.bDead || !E.bCanMove) continue;

        if (!E.bMoveLocked)   // 冲锋锁定期间不改方向
        {
            switch ((EMovementBehavior)E.MovementBehaviorType)
            {
            case EMovementBehavior::FollowPlayer:
                E.BehaviorTargetPos = PlayerPos; break;

            case EMovementBehavior::StayInRangeFromPlayer:
                // ActualTargetRange 在 Spawn 时一次性随机：range + rand(-randomization, +randomization)
                E.BehaviorTargetPos = PlayerPos
                    + E.ActualTargetRange * (E.Pos - PlayerPos).GetSafeNormal();
                break;

            case EMovementBehavior::TargetRandPos:
                if (FVector2D::Distance(E.Pos, E.BehaviorTargetPos) <= EqualityPrecision)
                    E.BehaviorTargetPos = ZoneService->GetRandPos(Rng);
                break;

            case EMovementBehavior::TargetRandPosAroundPlayer:
                if (FVector2D::Distance(E.Pos, E.BehaviorTargetPos) <= EqualityPrecision)
                {
                    const float A = E.ActualTargetRange;
                    E.BehaviorTargetPos = ZoneService->ClampToMap(
                        PlayerPos + FVector2D(Rng.RandRange(-A, A), Rng.RandRange(-A, A)));
                }
                break;

            case EMovementBehavior::FollowRandPosAroundPlayer:
                // Spawn 时固定偏移向量 → 平行跟随
                E.BehaviorTargetPos = PlayerPos + E.FixedOffsetFromPlayer;
                break;

            case EMovementBehavior::PatrolEdgesOfMap:
                TickPatrol(E, PlayerPos); break;
            }
            E.CurrentMovement = (E.BehaviorTargetPos - E.Pos);
            if (FVector2D::Distance(E.Pos, E.BehaviorTargetPos) <= EqualityPrecision)
                E.CurrentMovement = FVector2D::ZeroVector;   // StayInRange 距离 ≤10 px 停
        }

        // 速度合成
        const float Sp = FMath::Max(0.f, E.Speed + E.BonusSpeed
                                       + E.DecayingBonusSpeed + E.SpeedRandValue);
        const FVector2D MoveInput = E.CurrentMovement.GetSafeNormal() * Sp;
        E.Velocity = MoveInput - E.GetNextKnockbackValue();   // ★ 减法合入
    }
}
```

### 2.3 减速恢复

```cpp
void UEnemySubsystem::TickDecayingSpeed(FEnemyState& E)
{
    if (E.DecayingBonusSpeed > 0.f)      E.DecayingBonusSpeed = FMath::Max(0.f, E.DecayingBonusSpeed - 1.f);
    else if (E.DecayingBonusSpeed < 0.f) E.DecayingBonusSpeed = FMath::Min(0.f, E.DecayingBonusSpeed + 5.f);
}

void UEnemySubsystem::AddDecayingSpeed(FEnemyState& E, float Value)
{
    // 已为负时新增值 /20；下限保护 -(Speed × 0.8)
    if (E.DecayingBonusSpeed < 0.f) Value /= 20.f;
    E.DecayingBonusSpeed = FMath::Max(E.DecayingBonusSpeed + Value, -(E.Speed * 0.8f));
}
```

敌人命中玩家后对自身 `AddDecayingSpeed(-200)`。

### 2.4 击退（见 D04 §10.5）

`GetNextKnockbackValue(DeltaTime)` 用指数衰减 `Knockback *= Exp(-6.3216 * DeltaTime)`（原作每帧 `lerp(→0, 0.1)`）；击退期间敌人 Hitbox 关闭（`KnockbackLen > MoveInputLen`）。

```cpp
void UEnemySubsystem::ChargingStartShoot(FEnemyState& E, const FEnemyBehaviorRow& B)
{
    const FVector2D PlayerPos = Player->GetPos2D();
    FVector2D TargetPos = PlayerPos;
    if (B.ChargeTarget == EChargeTarget::RandomPointNearPlayer)
    {
        const float R = B.MaxRange / 5.f;      // max_range 300 → ±60
        TargetPos += FVector2D(Rng.RandRange(-R, R), Rng.RandRange(-R, R));

    E.ChargeDirection = TargetPos - E.Pos;
    E.bCanMove = false;                        // ★ 蓄力期间定身

void UEnemySubsystem::ChargingShoot(FEnemyState& E, const FEnemyBehaviorRow& B)
{
    E.bCanMove = true;
    E.bMoveLocked = true;                      // ★ 锁定方向
    E.BonusSpeed = B.ChargeSpeed * AccessibilitySpeed;
    E.CurrentMovement = E.ChargeDirection;
    E.ChargeTimeLeft = B.ChargeDuration;                      // 秒

}

void UEnemySubsystem::ChargingEnd(FEnemyState& E)
{ E.bMoveLocked = false; E.BonusSpeed = 0.f; }
```

### 3.3 射击 `ShootingAttack`

```cpp
void UEnemySubsystem::ShootingShoot(FEnemyState& E, const FEnemyBehaviorRow& B)
{
    FVector2D TargetPos = Player->GetPos2D();               // ★ 无预判，直接指向当前位置
    if (B.bShootInUnitDirection) TargetPos = E.Pos + E.CurrentMovement;

    const int32 N = B.NumberProjectiles;
    for (int32 i = 0; i < N; ++i)
    {
        const float BaseRot = (TargetPos - E.Pos).GetSafeNormal().ToAngle();
        float Rot = Rng.RandRange(BaseRot - B.ProjectileSpread, BaseRot + B.ProjectileSpread);
        if (B.bRandomDirection) Rot = Rng.RandRange(-PI, PI);
        if (B.bConstantSpread && N > 1)
        {
            const float Chunk = (2.f * B.ProjectileSpread) / (N - 1);
            Rot = BaseRot - B.ProjectileSpread + i * Chunk;  // ★ 等分扇形
        }

        FVector2D SpawnPos = E.Pos;
        if (B.bSpawnProjectilesOnTarget) SpawnPos = TargetPos;   // 玩家脚下生成
        if (B.bSpawnOnlyOnBorders)
        {
            const float A = B.bConstantSpread ? i * (2.f * PI / N) : Rng.RandRange(0.f, 2.f * PI);
            SpawnPos += FVector2D(FMath::Cos(A), FMath::Sin(A)) * (B.ProjectileSpawnSpread / 2.f);
        }
        else if (!B.bAtleastOneOnTarget || i != 0)
        {
            const float S = B.ProjectileSpawnSpread / 2.f;
            SpawnPos += FVector2D(Rng.RandRange(-S, S), Rng.RandRange(-S, S));
        }
        EnemyProjectileSubsystem->Spawn(SpawnPos, Rot, B, CurrentWave);
    }
}
```

敌弹伤害：`final = round(int(base × (Acc.damage + Sd)) × (1 + EF))`，`base = damage + (W-1) × damage_increase_each_wave`。

```cpp

{

        }
```

### 5.4 触发与重复调度（★ 按整秒采样）

```cpp
void UBrotatoWaveManager::Step(float DeltaTime)
{
    WaveTimeLeft -= DeltaTime;
    if (WaveTimeLeft <= 0.f) { OnWaveTimeout(); return; }

    // ★ 保留原作"按整秒采样"语义：把连续时间量化到整秒再比较
    const int32 TimeLeft = FMath::CeilToInt(WaveTimeLeft);
    if (TimeLeft == LastSecondChecked) return;          // 每秒只检查一次
    LastSecondChecked = TimeLeft;

    const int32 Diff = RunSubsystem->GetCurrentDifficulty();
    for (int32 i = ActiveGroups.Num() - 1; i >= 0; --i)
    {
        const FBrotatoWaveGroupData& G = ActiveGroups[i].Def;
        const bool bStartWave = G.bIsBoss
            || (G.bIsNeutral && HasRule(Rule_TreesStartWave)
                && TimeLeft >= WaveDurationSeconds - 5);

        if (Diff < G.MinDifficulty) continue;
        if (!(TimeLeft <= WaveDurationSeconds - G.SpawnTiming || bStartWave)) continue;

        if (Rng.ChanceSuccess(G.SpawnChance)) OnGroupTimingReached.Broadcast(G);
        if (G.Repeating > 0) RegisterRepeat(ActiveGroups[i], TimeLeft);   // ★ -1 → 只此一次
        ActiveGroups.RemoveAt(i);                       // 首次触发后即从主列表移除
    }

    // 重复组
    for (FWaveGroupRuntime& R : RepeatingGroups)
    {
        if (TimeLeft > R.NextSpawnTimeLeft) continue;
        if (Rng.ChanceSuccess(R.Def.SpawnChance)) OnGroupTimingReached.Broadcast(R.Def);
        --R.RepeatingLeft;
        R.CurrentInterval = FMath::Max(R.Def.MinRepeatingInterval,
                                       R.CurrentInterval - R.Def.ReduceRepeatingInterval);
        R.NextSpawnTimeLeft -= R.CurrentInterval;
    }
    RepeatingGroups.RemoveAll([](const FWaveGroupRuntime& R){ return R.RepeatingLeft <= 0; });
}
```

第 k 次刷怪时刻：
$$t_1 = \text{spawn\_timing},\quad t_{k+1} = t_k + \max\big(\text{min\_interval},\ \text{interval} - (k-1)\cdot\text{reduce}\big)$$

验收 `S03`：W3 g2（interval=7, reduce=1, min=3）→ 间隔序列 `7,6,5,4,3,3,3,…`
验收 `S04`：`Repeating = -1` 的组**只触发一次**。

### 6.2 单批数量

```cpp
void ABrotatoEntitySpawner::OnGroupTimingReached(const FBrotatoWaveGroupData& G)
{
    EnemySubsystem->EnforceMaxEnemies(CurrentWaveMaxEnemies);   // 每次触发时剔除

    const FVector2D GroupBase = ComputeGroupBasePos(G);
    for (const FBrotatoWaveUnitData& U : G.WaveUnitsData)
    {
        float Mod = 0.f; int32 FlatMod = 0;
        if (U.Type == EWaveUnitType::Enemy)   Mod     += Snapshot.NumberOfEnemies / 100.f;
        if (U.Type == EWaveUnitType::Neutral) FlatMod += (int32)Snapshot.Trees;

        int32 Number = Rng.RandInt(U.MinNumber + FlatMod, U.MaxNumber + FlatMod);

        if (Mod < 0.f && Number > 1)
        {   // 减怪：逐个 roll |Mod| 剔除，最少留 1
            int32 Removed = 0;
            for (int32 i = 0; i < Number; ++i) if (Rng.StrictRoll(FMath::Abs(Mod))) ++Removed;
            Number = FMath::Max(1, Number - Removed);
        }
        else if (Mod > 0.f)
        {   // 加怪
            const int32 Additionals = FMath::Max(0, BrotatoMathInt::BrotatoTruncInt(Number * (Mod - 1.f)));
            int32 ToAdd = 0;
            for (int32 i = 0; i < Number + Additionals; ++i)
                if (Rng.StrictRoll(FMath::Abs(Mod))) ++ToAdd;
            Number += ToAdd;
        }

        if (U.Type == EWaveUnitType::Neutral)
        {   // ★ 中立（树）：期望取整
            const float Total = Number * U.SpawnChance;
            int32 Nb = FMath::FloorToInt(Total);
            if (Rng.ChanceSuccess(Total - Nb)) ++Nb;
            for (int32 i = 0; i < Nb; ++i) Enqueue(U, GetSpawnPos(G, GroupBase));
        }
        else
        {   // 普通敌人：逐只 roll
            for (int32 i = 0; i < Number; ++i)
                if (Rng.ChanceSuccess(U.SpawnChance)) Enqueue(U, GetSpawnPos(G, GroupBase));
        }
    }
}
```

### 6.3 位置规则

```cpp
FVector2D ABrotatoEntitySpawner::ComputeGroupBasePos(const FBrotatoWaveGroupData& G)
{
    const FVector2D Min = ZoneService->GetMin(), Max = ZoneService->GetMax();
    const float d = G.SpawnDistAwayFromEdges;
    if (G.Area != -1)
        return { Rng.RandRange(Min.X + d, Max.X - G.Area - d),
                 Rng.RandRange(Min.Y + d, Max.Y - G.Area - d) };
    return { Rng.RandRange(Min.X, Max.X), Rng.RandRange(Min.Y, Max.Y) };
}

FVector2D ABrotatoEntitySpawner::GetSpawnPosInArea(FVector2D Base, int32 Area, float d, bool bEdge)
{
    const FVector2D Min = ZoneService->GetMin(), Max = ZoneService->GetMax();
    if (bEdge)
    {
        switch (Rng.RandInt(0, 3))
        {
        case 0: return { Rng.RandRange(Min.X+64, Max.X-64), Min.Y + 64 };   // TOP
        case 1: return { Min.X + 64, Rng.RandRange(Min.Y+64, Max.Y-64) };   // LEFT
        case 2: return { Rng.RandRange(Min.X+64, Max.X-64), Max.Y - 64 };   // BOTTOM
        default:return { Max.X - 64, Rng.RandRange(Min.Y+64, Max.Y-64) };   // RIGHT
        }
    }
    if (Area == -1)
        return { Rng.RandRange(Min.X+d, Max.X-d), Rng.RandRange(Min.Y+d, Max.Y-d) };

    const FVector2D C = ZoneService->Clamp(Base, Area);   // clamp 到 [Min+64+Area/2, Max-64-Area/2]
    return { Rng.RandRange(C.X - Area*0.5f, C.X + Area*0.5f),
             Rng.RandRange(C.Y - Area*0.5f, C.Y + Area*0.5f) };
}

FVector2D ABrotatoEntitySpawner::GetSpawnPos(const FBrotatoWaveGroupData& G, FVector2D Base)
{
    FVector2D P = GetSpawnPosInArea(Base, G.Area, G.SpawnDistAwayFromEdges, G.bSpawnEdgeOfMap);
    // ★ 重 roll 时 area 强制 -1
    while (FVector2D::Distance(P, Player->GetPos2D()) < MinDistFromPlayer)
        P = GetSpawnPosInArea(Base, -1, G.SpawnDistAwayFromEdges, G.bSpawnEdgeOfMap);
    return P;
}
```

> ★ **不是"屏幕外圆环"**：三种模式（全图任意点 / 4 边内缩 64 / 组团方块），唯一硬约束是**离玩家 ≥ 300 px**。

### 8.1 方案决议（§00 §4 / §09 §11.1）

```cpp
void IntegrateMovement(FVector2D& Pos, FVector2D Velocity, float DeltaTime, float Radius)
{
    FVector2D Delta = Velocity * DeltaTime;
    FSweepHit Hit;
    if (SweepAgainstWalls(Pos, Delta, Radius, 0.08f, Hit))
    {
        Pos += Hit.Motion;
        const FVector2D Slide = ProjectOnPlane(Velocity, Hit.Normal) * DeltaTime;

        Pos += Hit2.Motion;
    }
    else Pos += Delta;
}
```

```cpp
void UPickupSubsystem::SpawnGold(const FEnemyState& E, int32 Value, int32 GoldSpread)
{
    for (int32 i = 0; i < Value; ++i)
    {
        FMaterialInstance M;
        const float Dist = Rng.RandRange(50.f, 100.f + GoldSpread);
        const float A    = Rng.RandRange(0.f, 2.f * PI);
        M.Pos = E.Pos;
        M.PushBackDest = E.Pos + FVector2D(FMath::Cos(A), FMath::Sin(A)) * Dist;

        if (RunSubsystem->GetBonusGold() > 0)
        {   // ★ bonus_gold 是「下一波材料价值翻倍额度池」
            M.Value += FMath::Min(M.Value, RunSubsystem->GetBonusGold());
            M.Boosted = 2; M.Scale = 1.25f;
            RunSubsystem->RemoveBonusGold(1);
        }
        if (Rng.StrictRoll(Snapshot.InstantGoldAttracting / 100.f)) M.Target = EAttractTarget::Player;
        Add(M);
    }
    // ★ 溢出合并：场上 > 50 时，随机挑一个已有材料 Value += E.Value，Scale += Value × 0.05
    if (Materials.Num() > BrotatoConst::MaxGolds) MergeIntoRandom(E.Value);
}
```

```cpp
void UPickupSubsystem::Step(float DeltaTime)   // 模拟阶段 S10
{
    for (FMaterialInstance& M : Materials)
    {
        if (!M.bActive) continue;
        if (FVector2D::Distance(M.Pos, M.PushBackDest) > 20.f)
        {
            // 抛散：原作 lerp(dest, delta×5) → 帧率无关的指数趋近
            const float A = 1.f - FMath::Exp(-5.f * DeltaTime);
            M.Pos = FMath::Lerp(M.Pos, M.PushBackDest, A);
        }
        else if (M.IdleTimeLeft > 0.f) { M.bMonitorable = true; M.IdleTimeLeft -= DeltaTime; }
        else if (M.Target != EAttractTarget::None)
        {
            const FVector2D T = (M.Target == EAttractTarget::Player) ? Player->GetPos2D() : GoldBagPos;
            M.Pos += (T - M.Pos).GetSafeNormal() * (M.CurrentSpeed * DeltaTime);
            M.CurrentSpeed += 1200.f * DeltaTime;                     // ★ 原作每帧 +20
        }
    }
}
```

```cpp
void UStructureSubsystem::CheckSpawn()
{
    const float SpawnRadius = FMath::Min(600.f, 400.f + HookRegistry->Num(Hook_Structures) * 10.f);
    for (const FBrotatoHookEntry& E : HookRegistry->Get(Hook_Structures))
    {

float ApplyStructureCooldownReduction(float BaseCdSeconds, float Total)
```

```cpp
void UEnemySubsystem::ProcessDrops(const FEnemyState& E, const FEnemyRow& Row)
{
    if (!E.bCanDropLoot) return;

    // ① 材料
    float P = FBrotatoEconomyMath::GoldDropChance(CurrentWave, Snapshot.GoldDrops,
                 Snapshot.EnemyGoldDrops, Snapshot.DiffGoldDrops,
                 !E.bIsNeutral, bIsHordeWave, Row.bAlwaysDropConsumables);
    // ★ 中性单位无视概率
    if (E.bIsNeutral || Rng.ChanceSuccess(P))
        PickupSubsystem->SpawnGold(E, E.Value, Row.GoldSpread);

    // ② 消耗品
    if (!Row.bCanDropConsumables) return;
    float DropP = FBrotatoEconomyMath::ConsumableDropChance(Row.BaseDropChance, Snapshot.Luck,
                                                            EndlessFactor, bIsEndless);
    if (!Rng.ChanceSuccess(DropP) && !Row.bAlwaysDropConsumables) return;

    float BoxP = FBrotatoEconomyMath::ItemBoxChance(Row.ItemDropChance, Snapshot.Luck,
                                                    ItemsSpawnedThisWave);
    if (Row.bAlwaysDropConsumables && Row.ItemDropChance >= 1.f && CurrentWave <= 20) BoxP = 1.f;

    if (Rng.ChanceSuccess(BoxP))
    {
        const FName Box = (E.bIsBoss && CurrentWave <= 20) ? "consumable_legendary_item_box"
                                                           : "consumable_item_box";
        PickupSubsystem->SpawnConsumable(Box, E.Pos);
        ++ItemsSpawnedThisWave;      // ★ 反刷宝箱：下次分母 +1
    }
    else
    {
        const int32 Tier = Rng.RandInt((int32)Row.MinConsumableTier, (int32)Row.MaxConsumableTier);
        PickupSubsystem->SpawnConsumable(GetConsumableToDrop(Tier), E.Pos);
    }
}
```

## 12. 波末结算流程（逻辑帧外，事件驱动）

```
OnWaveTimeout():
 1. LogRunInfo()
 2. IsLastWave() && !bLost → bRunWon = true
 3. ChallengeService->CheckCountedChallenges()
 4. chal_reckless 检查（Health == chal.value）
```
