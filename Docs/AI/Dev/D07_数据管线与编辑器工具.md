# D07 · 数据管线、DataTable Schema 与编辑器工具

> **模块**：`BrotatoData`（资产定义）+ `BrotatoEditor`（Commandlet / Validator）+ `Tools/`（Python）
> **里程碑**：M0 建表结构 → M2 导入数值 → M4 全量数据齐备
> **上游规格**：`Docs/09 §12`、`Docs/05 §0`、各章数值表

**铁律**：**2000+ 条数据不得手工录入。** 全部经由 `.tres → CSV → DataTable` 管线导入，并由 Validator 把关。

## 2. DataAsset 层次

```cpp
UCLASS(Abstract)
class BROTATODATA_API UBrotatoItemParentData : public UPrimaryDataAsset
{
    GENERATED_BODY()
public:
    UPROPERTY(EditDefaultsOnly) FName MyId;
    UPROPERTY(EditDefaultsOnly) bool  bUnlockedByDefault = false;
    UPROPERTY(EditDefaultsOnly) TSoftObjectPtr<UTexture2D> Icon;
    UPROPERTY(EditDefaultsOnly) FName NameKey;                   // 本地化键
    UPROPERTY(EditDefaultsOnly) EBrotatoTier Tier = EBrotatoTier::Common;
    UPROPERTY(EditDefaultsOnly) int32 Value = 1;
    UPROPERTY(EditDefaultsOnly) TArray<FBrotatoEffectDef> Effects;
    UPROPERTY(EditDefaultsOnly) FName TrackingTextKey;

    FGameplayEffectSpecHandle BuildStatSpec(UAbilitySystemComponent*, TSubclassOf<UGameplayEffect>) const;
    bool HasAnyStatModifier() const;
    FText GetEffectsText(bool bColored = true) const;
};

UCLASS() class UBrotatoItemData : public UBrotatoItemParentData
{
    UPROPERTY(EditDefaultsOnly) int32 MaxNb = -1;                // -1 无限 / 1 唯一
    UPROPERTY(EditDefaultsOnly) TArray<FItemAppearance> ItemAppearances;
    UPROPERTY(EditDefaultsOnly) TArray<FGameplayTag> Tags;       // wanted_tags 匹配
};

UCLASS() class UBrotatoCharacterData : public UBrotatoItemData
{
    UPROPERTY(EditDefaultsOnly) TArray<FGameplayTag> WantedTags;
    UPROPERTY(EditDefaultsOnly) TArray<TSoftObjectPtr<UBrotatoWeaponData>> StartingWeapons;
};

UCLASS() class UBrotatoWeaponData : public UBrotatoItemParentData
{
    UPROPERTY(EditDefaultsOnly) FName WeaponId;                  // ★ 解锁与 weapon_bonus 粒度
    UPROPERTY(EditDefaultsOnly) EWeaponType Type = EWeaponType::Melee;
    UPROPERTY(EditDefaultsOnly) TArray<TObjectPtr<UBrotatoSetData>> Sets;
    UPROPERTY(EditDefaultsOnly) FBrotatoWeaponStats Stats;
    UPROPERTY(EditDefaultsOnly) TSoftObjectPtr<UBrotatoWeaponData> UpgradesInto;   // Tier IV 为空
    UPROPERTY(EditDefaultsOnly) TSubclassOf<UGA_WeaponAttack> AttackAbility;       // 通常共用
};

UCLASS() class UBrotatoConsumableData : public UBrotatoItemData
{
    UPROPERTY(EditDefaultsOnly) bool bToBeProcessedAtEndOfWave = false;
    UPROPERTY(EditDefaultsOnly) TArray<TSoftObjectPtr<USoundBase>> PickupSounds;
    UPROPERTY(EditDefaultsOnly) bool bHasFixedTier = false;
    UPROPERTY(EditDefaultsOnly) EBrotatoTier FixedTier = EBrotatoTier::Legendary;
};

UCLASS() class UBrotatoUpgradeData : public UBrotatoItemData
{ UPROPERTY(EditDefaultsOnly) FName UpgradeId; };                // ★ 解锁粒度

UCLASS() class UBrotatoSetData : public UBrotatoItemParentData
{
    UPROPERTY(EditDefaultsOnly) FGameplayTag SetTag;
    UPROPERTY(EditDefaultsOnly) TArray<FBrotatoEffectDefList> Bonuses;   // 固定 5 档
};
```

## 3. DataTable Schema（逐列定义）

> 约定：`RowName` = `MyId`（除注明者）。所有 `float` 保留 4 位小数。布尔列用 `True/False`。

### 3.1 `DT_Items`（179 行）

| 列 | 类型 | 说明 |
|---|---|---|
| `MyId` | Name | `item_xxx` |
| `NameKey` | Name | 本地化键 |
| `Tier` | Enum | Common / Uncommon / Rare / Legendary |
| `Value` | int32 | 基础价格（**★ 约 100 项待补，见 §7**） |
| `MaxNb` | int32 | −1 无限 / 1 唯一 |
| `bUnlockedByDefault` | bool | |
| `Tags` | Array\<GameplayTag\> | `wanted_tags` 匹配用 |

价格区间参考：I 15–30 / II 35–50（`item_pocket_factory` = 75 例外）/ III 60–90 / IV 80–130（最贵 `item_mammoth` = 130）。

### 4.2 ★ Effect 转换规则（`effect_rules.py`）

```python
# .tres 字段 → FBrotatoEffectDef
#
# 1) script 路径 → Kind
#    effects/items/effect.gd                       → StatModifier（再看 storage_method）
#    effects/items/stat_gains_modification_effect  → GainModifier
#    effects/items/stat_cap_effect                 → StatModifier(Replace)
#    effects/items/stat_with_max_effect            → StatWithMax
#    effects/items/class_bonus_effect              → ClassBonus
#    effects/items/weapon_bonus_effect             → WeaponBonus
#    effects/items/gain_stat_for_every_stat_effect → StatLink
#    effects/items/convert_stat_effect             → StatConvert
#    effects/items/chance_stat_damage_effect       → Hook
#    effects/items/healing_effect                  → Hook（Instant GE_Heal）
#    effects/items/item_exploding_effect           → Exploding
#    effects/items/projectile_effect               → Hook
#    effects/items/structure_effect | turret_effect→ Structure
#    effects/items/burn_chance_effect              → Burning
#    effects/weapons/*                             → Marker / Burning / Exploding / WeaponStack
#
# 2) ★ 优先级修正：custom_key 非空 → 强制 Kind = Hook（即使 storage_method == SUM）
#
# 3) key → AttributeTag（查 name_map）
#    "stat_max_hp"         → Brotato.Attribute.Primary.MaxHp
#    "gain_stat_speed"     → Brotato.Attribute.Gain.Speed
#    "dodge_cap"           → Brotato.Attribute.Limit.DodgeCap
#    "xp_gain"             → Brotato.Attribute.Secondary.XpGain
#    bool 型（no_heal 等） → Kind = Rule，HookTag = Brotato.Rule.NoHeal
#    数组型（36+）          → Kind = Hook，HookTag = Brotato.Hook.XxxYyy
#
# 4) storage_method: 0 SUM → Additive / 1 KEY_VALUE → Hook / 2 REPLACE → Override
#
# 5) 子类扩展字段 → 对应 Def 字段
#    chance / max_value / nb_stat_scaled / stat_scaled / perm_only
#    pct_converted / to_stat / to_value / set_id / weapon_id
#    burning_data{chance,damage,duration→NumTicks,spread,type}
#    spawn_cooldown / scene / stats / spawn_around_player / can_be_grouped
#    weapon_stats / auto_target_enemy / cooldown
#
# 5b) ★★ 时间单位换算（必须在导入期完成，运行时不得出现帧值）
#    凡原作语义为「物理帧」的字段 → 除以 60 写入 *Seconds 列（float，不取整）：
#      cooldown → CooldownSeconds                  （60 → 1.0）
#      max_cd_randomization → CdRandomizationSeconds
#      initial_cooldown → InitialCooldownSeconds
#      charging_projectiles_cooldown → ...Seconds  （15 → 0.25）
#      spawn_cooldown → SpawnCooldownSeconds       （保留负值语义）
#      boost_timer / check_state_timer 等           → *Seconds
#    「每帧 +N」类速率 → 乘 60 写入「每秒」列：
#      projectile rotation 25°/帧 → 1500 °/s
#      吸附加速 20/帧             → 1200 px/s²
#    「每帧 ×k」类衰减 → 写入衰减率 Rate = -60·ln(k)：
#      击退 0.9/帧 → KnockbackDecayRate = 6.3216
#    burning duration（tick 次数）→ NumTicks 保持整数，另写 TickInterval = 0.5 s
#
# 6) 文本字段：text_key / effect_sign / custom_args[{arg_index, arg_value, arg_sign, format}]
#
# 7) 未识别字段 → 写入 report.md 的 "UNMAPPED" 段，CI 门禁：非空则失败
```

CSV 中 `Effects` 列用**单行 JSON 数组**表示，UE 侧靠 `FBrotatoEffectDef` 的 `ImportTextItem` 解析。
